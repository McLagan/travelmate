Overview

Data the app collects by itself. Red means something needs a look.

Vignettes & toll crossings

Vignette validity is read from the name (“10-Day”, “1-Month”, “Annual”…); records without it are not used for trips. Hidden records and overridden prices apply to every trip immediately.

Motorway tolls (pay per trip)

Official price lists are checked automatically; a new list is used only if it can be read.

Rate per operator (estimated countries)

Toll = km on the operator's motorway × rate (car, VAT included); flat = fixed fee per trip. Rows with a yellow background use the default rate — enter the operator's rate in “Our €” (Italy: “Info pedaggio” on the operator's website, class A; France: average class 1 rate of the operator).
